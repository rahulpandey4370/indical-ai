# **App Name**: IndiCal AI

## Core Features:

- UI Shell & Calendar Dashboard: Initial setup with Next.js, focusing on the calendar-based dashboard for selecting and viewing nutritional logs.
- Gemini Vision Integration: Implement Gemini Vision to analyze images of Indian food and identify dishes, estimate nutritional content using Indian food heuristics. It will leverage Google's advanced image recognition tool to create more nuanced analyses that cater to local ingredients and culinary practices, going beyond the current nutritional assessment.
- AI Analysis Tool Refinement: The AI analysis is enhanced with an analysis tool refinement prompt feature, so the output can be tweaked by the user using natural language.
- Atomic Commitment to Cloud Persistence: Implement logic and wire up Azure Cosmos DB and Blob Storage such that they ensure that every 'Commit to Journey' action represents an atomic operation that is persistently captured in the cloud.

## Style Guidelines:

- Primary color: Vibrant Saffron Orange (#FF9933) to reflect Indian culinary heritage, energy, and warmth.
- Background color: Off-white (#FAF9F6) to provide a clean, neutral backdrop that emphasizes the food images. Dark mode: Dark slate gray for a comfortable viewing experience.
- Accent color: Turmeric Yellow (#FFC107) to draw attention to important UI elements, such as CTAs.
- Body and headline font: 'Inter' for a clean, modern look suitable for both headlines and body text.
- Use clean, modern icons to represent different food categories, actions, and nutritional information.
- Employ a minimalist layout with generous spacing and clear visual hierarchy to ensure easy navigation and readability.
- Use subtle animations and transitions to provide feedback and guide the user through the application, enhancing the overall user experience.
